# 生成后的报告检查

初始化器将检查器和所需依赖声明复制进新项目；安装项目依赖后执行：

```bash
npx playwright install chromium
npm run check
```

检查指定文件：`npm run check -- slides.md`。已有 Chrome 可加 `--browser chrome`；`--strict` 把提醒也作为失败。`--out <directory>` 指定独立输出目录；`--url http://localhost:3030/` 使用已经启动且与源稿对应的预览。没有 `--url` 时自动启动独立预览并在完成后关闭。

检查器不修改源稿。默认输出 `.slidev-check/<源稿名>/`：

- `report.json`：每页标题、源文件位置、规则代码和错误/提醒。
- `index.html`：中文说明和逐页截图。
- `slide-01.png` 等：实际浏览器画面。

## 修正流程

1. 先读 JSON，按页确认错误；再看该页截图。
2. 越界或页脚重叠时精简或拆页；缺图时核对真实文件；目录错页时更新目标。
3. 标题长、内容块相交、目录文字与目标不同是提醒，结合截图和语义判断。不要盲目改写正确的目录名称。
4. 修改源稿后重跑。没有未处理错误、提醒均经处理后，继续人工核对研究事实、引用和图表。

退出码：0 无错误；1 有错误（或严格模式下有提醒）；2 检查未完成。必须区分“未完成”和“检查通过”。

浏览器默认显示状态的检查不覆盖所有动画步骤、所有自定义 CSS 重叠、论文事实、统计正确性或 PowerPoint 导出。单独查看这些内容。自定义预解析插件可能改变页数；若页数不一致，核查源稿和实际预览，不忽略 `DECK_MISMATCH`。
