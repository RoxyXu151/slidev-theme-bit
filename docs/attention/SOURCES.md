- [对应 PDF](https://arxiv.org/pdf/1706.03762v7)，15 页。
- [对应 HTML](https://arxiv.org/html/1706.03762v7)。

不要把不同版本摘要、表格或正文的数值混在同一比较中。本例的翻译结果严格采用 v7 表 2：英德 Base/Big 为 27.3/28.4，英法为 38.1/41.8。v7 §6.1 正文英法 Big 有 41.0 的不同表述，这里保留表 2 口径，不替原作者修订数据。
