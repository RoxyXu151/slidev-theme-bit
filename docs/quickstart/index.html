01选一份合适的起步稿

起步稿保留待补充标记和讲稿提示，帮助你组织内容；完整论文示例展示填入真实材料后的效果。

本地使用需要 Node.js 22.18 以上。先下载仓库并安装依赖：

git clone https://github.com/RoxyXu151/slidev-theme-bit.git
cd slidev-theme-bit
npm ci

再创建独立报告目录，主题仓库仍保留作为参考：

npm run create:deck -- ../my-paper --template paper --theme .
cd ../my-paper
npm install
npm run dev

也可在浏览器编辑完整示例

浏览器入口使用 StackBlitz；首次会安装依赖，需要其支持的桌面浏览器和网络。组会、答辩的起步稿不会带入示例论文的实验结果。

02把材料和源稿一起交给 AI

提供论文、真实结果和所选起步稿 slides.md。有 AI 编程助手时，在主题仓库中调用 $bit-slidev；也可参考仓库的 完整写作提示词。

请基于我提供的论文，用北理工主题制作论文阅读汇报。
听众：本方向研究生；时长：12 分钟；总页数：12 页。
先给出每页要回答的问题，再填写所选起步稿 slides.md。
保留来源和讲稿，区分论文结论与自己的分析。
缺失材料写 [待补充]，不要编造数据或文献。
复用现有版式，保存后运行报告检查，根据截图修正再交付。

本项目提供主题与写作流程，不内置在线 AI 服务，也不会自动替你验证论文事实。

03预览、修改，再看一次

打开启动命令给出的本地地址。修改 slides.md 并保存，网页会更新；方向键翻页，P 查看讲稿，O 查看总览。

请放大第 5 页的架构图，保留比例和图片出处。
请精简第 10 页，只保留最有证据支持的结论。

04让检查器先找排版问题

npx playwright install chromium
npm run check

检查器会启动临时预览，逐页截图，结束后关闭。打开 .slidev-check/slides/index.html 看问题和截图；AI 可读取同目录下的 report.json，修改后重新检查。

检查包括：正文越界、页脚重叠、缺失图片、长标题、内容块相交和目录错页。提醒需要结合截图确认；检查通过仍需核对引用、数字与结论。

已安装 Chrome 时可用 npm run check -- --browser chrome。检查器检查浏览器默认显示状态，不检查全部动画步骤或 PowerPoint 导出。

05展示，或导出分享

npm run build
npm run export

网页产物在 dist/，PDF 为 slides.pdf。如需 PPTX，可选择保留外观的图片版，或可继续编辑的对象版：

npx slidev export slides.md --format pptx --output slides.pptx
npx slidev export slides.md --format pptx-editable --output slides-editable.pptx --no-with-clicks

图片版文字无法单独编辑；可编辑版可能出现换行、图片或效果差异，交付前请在 PowerPoint 中打开核对。Slidev 导出说明
