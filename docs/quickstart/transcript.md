# 两分钟操作演示：文字步骤

视频使用《Attention Is All You Need》完整示例，演示真实的本地 Slidev 预览、源稿修改和报告检查结果。视频没有连接在线 AI；请在自己的 AI 工具中执行材料整理和生成任务。

| 时间 | 操作 |
| --- | --- |
| 00:00–00:10 | 打开新手指南，认识五步流程与网页演示 |
| 00:10–00:32 | 选择论文阅读起步稿，查看创建命令与 AI 任务描述 |
| 00:32–00:45 | 打开完整论文示例，用目录跳转到方法页 |
| 00:45–01:06 | 在源稿编辑区修改封面标题并保存，观察真实预览更新 |
| 01:06–01:39 | 实际运行报告检查，查看中文结果和逐页截图；JSON 可交给 AI 修正 |
| 01:39–02:00 | 打开 Slidev 的导出入口，并查看指南中的 PDF / PPTX 说明 |

源稿编辑区是录屏时用于显示本地文件修改的辅助页面；不是主题内置的在线编辑器。正常使用时可以用自己的编辑器，或让 AI 编程助手修改文件。

操作命令、生成后检查、输出格式区别及常见问题见[中文版指南](../GETTING_STARTED.md)和[English guide](../GETTING_STARTED.en.md)。
